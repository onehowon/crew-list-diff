# 평가 결과 (합성 데이터)

- 대상: 대조·분류 엔진(lib/). 메일 해석은 규칙 기반(데모). 실제 서비스의 LLM 추출 성능은 포함되지 않음.
- **합성 데이터 결과라 실제 현장 명부·메일에서는 다를 수 있음.** 현장 업무시간 절감은 주장하지 않음(후속 PoC).

- 재현: `node eval/run.mjs --split all`(개발·H1·H2, 현재 코드). H3는 `node eval/run.mjs --split h3` 1회 실행 전용(결과 파일이 있으면 재실행 거부).
