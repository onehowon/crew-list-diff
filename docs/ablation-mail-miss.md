# AI가 메일 지시를 놓치면 (새 시험 H5 60쌍)

| 지표 | 정상 | 쌍마다 지시 1줄 놓침 | 지시 전부 놓침(최악) |
|---|---|---|---|
| 메일로 요청한 변경: 예상된 변경으로 표시 | 150 / 154 | 100 / 154 | 0 / 154 |
| 메일로 요청한 변경: 확인 필요·오류 의심으로 담당자에게 | 4 / 154 | 54 / 154 | 154 / 154 |
| 메일로 요청한 변경: 화면에서 사라짐 | 0 / 154 | 0 / 154 | 0 / 154 |
| 명부 자체의 오류(일·월 뒤바뀜 등)를 잡음 | 80 / 80 | 80 / 80 | 80 / 80 |
| 오류가 예상된 변경으로 덮임 | 0 | 0 | 0 |
| **요청이 수정본에 빠진 오류를 잡음** | **22 / 22** | **13 / 22** | **0 / 22** |
| 담당자가 하나씩 볼 항목(합계) | 185 | 228 | 316 |

- 메일 지시를 놓치면 그 변경은 "예상된 변경"이 아니라 담당자가 볼 항목으로 넘어갈 뿐 사라지지 않는다. 오류가 정상 변경으로 덮이지도 않는다.
- 단, "메일로 요청했는데 수정본에 빠진 오류"는 메일 지시를 읽어야만 찾을 수 있어, 지시를 놓친 만큼 함께 놓친다.
- 어느 경우에도 자동 확정은 없다. 모든 항목은 담당자가 반영·유지·선사 문의를 정해야 확정된다.
