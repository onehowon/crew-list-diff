# 새 시험 H5 설계 (엔진 실행 전에 작성·커밋)

목적: 기존 홀드아웃(H1~H4)은 모두 결과를 본 뒤 코드를 고쳤으므로, 검토량 감소(9.4% → 1.3%)가 **이미 본 데이터 밖에서도** 유지되는지 한 번 확인한다.

- 엔진·규칙·별칭 사전은 커밋 fc115c6 상태로 고정한다. 이 시험 결과를 본 뒤 코드를 고치면, 고친 뒤 값은 따로 표시하고 이 1회차 값은 그대로 둔다.
- 데이터: `eval/gen.mjs`의 생성기를 **새 시드 20261205**로 돌린 홀드아웃 60쌍. 사람·오류·메일·행 순서는 새로 뽑히고, 양식(한국어 머리글, 약어 머리글·미국식 날짜)은 H1·H2와 같은 종류다. 즉 "처음 보는 사례"이지 "처음 보는 양식"은 아니다.
- 비교: 본 엔진 / 엑셀식 비교(여권번호로 짝지음) / 엑셀식 비교 + 같은 메일 정보. 채점은 `eval/run.mjs`와 같은 코드.
- 실행: `node eval/h5.mjs` — 결과 파일이 있으면 다시 실행하지 않는다. 결과는 `docs/eval-H5-first-run.{json,md}`.
